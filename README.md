# دحروج — Roblox

نسخة Roblox من لعبة **دحروج** من **عبودين قيمز**. شخصيتك في Roblox، ومعك دحروج مرافق بالستايل اللي تختاره، وترمي دحاريج صغيرة.

## اللوبي: ساحة دحروج
- **البوابات دحاريج عملاقة فاتحة فمها.** تقف على اللسان الوردي، وبعد العد التنازلي تدخل الجولة. عيون البوابة تلحقك.
- **منصات الستايل:** جيلي، قماش، صلصال، فرو، فقاعة. تغيّر لون دحروجك المرافق ولون الدحاريج اللي ترميها.
- بوابة **الجبل** نايمة 💤 (قريباً).

## الأنماط
| النمط | اللاعبين | الوقت | الفكرة |
|---|---|---|---|
| ⚽ المرمى | 1–4 | 90ث | كل لاعب له ممر ومرمى وحارس دحروج يسرع مع الوقت. الأكثر أهداف يفوز. |
| 🫧 مطر الدحاريج | 1–8 | 120ث | دحاريج لابسة إكسسوارات تنزل من السماء. العادي نقطة، الذهبي 3، وسلسلة 5 تضاعف النقاط. |

## الرمي
- **كمبيوتر:** اضغط الماوس مطوّلاً للشحن، وأفلت باتجاه المؤشر.
- **جوال:** اضغط زر «ارمِ» مطوّلاً، صوّب بالكاميرا، وأفلت.
- أثناء الشحن يطلع خط نقاط يوضح المسار.

## العملات والفوز
مشاركة +10، والمراكز الثلاث الأولى +15 و+10 و+5، وكل نقطة +1. الفوز يُحسب لما يكون فيه أكثر من لاعب.
الحفظ في Studio يحتاج تفعيل: Game Settings › Security › Enable Studio Access to API Services.
